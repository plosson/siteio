# Users (Part 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give siteio users with passwords — one admin per server, tenant owners and members — with their own revocable keys, password login to the admin UI, and `siteio users` management, without changing what the god key, tenant keys and share codes can do.

**Architecture:** A file-per-user `UserStore` (like `GrantStore`) holds password hashes and key hashes. `AgentServer.authenticate()` learns `usr_` keys (header) and the `siteio_session` cookie (UI). Request handling switches from "scope" to a `Caller = { scope, admin }`, so every operator exemption is keyed on `admin` instead of "no tenant". User, session and `/me` routes live in a new `UserRoutes` module.

**Tech Stack:** Bun + TypeScript, `Bun.password` (argon2id), `bun:test`, Commander CLI, Alpine.js admin UI.

**Spec:** `docs/superpowers/specs/2026-10-19-device-login-users-design.md` — this plan is **Part 1** of its "Order of work" (user store, authorization, UI login, `users` commands, `agent password`, install changes). Device login, `login`/`logout` changes are Part 2, in a separate plan.

## Global Constraints

- Bun only: `bun test`, `bun run typecheck`. Never npm/node.
- Work on branch `feat/users` (create it from `main` before Task 1).
- CLI output: JSON on stdout (`--json`), human text on stderr (`utils/output.ts` helpers).
- Errors: `ValidationError` / `ApiError` / `ConfigError` from `utils/errors.ts`.
- User files: `<dataDir>/users/<username>.json`, folder mode `0700`, files `0600`.
- Usernames: `NAME_RE` from `tenants.ts` (`^[a-z0-9]([a-z0-9-]*[a-z0-9])?$`), at most 63 chars, lower-cased and trimmed on input. `admin` is reserved for the admin.
- Passwords: 8 to 1024 characters. Generated passwords: `randomBytes(18).toString("base64url")`.
- Keys: secret `usr_` + 32 random bytes base64url; id `key_` + 8 hex chars. Only `sha256(secret)` is stored.
- Session: `kind: "session"`, TTL 7 days, cookie exactly `siteio_session=<secret>; Path=/; HttpOnly; Secure; SameSite=Strict; Max-Age=604800`. A cookie request must carry `X-Siteio-UI: 1`.
- Rate limit: 10 failed password checks per minute per client IP, then 429. No per-username limit.
- God key, `ten_` tenant keys, share codes, `siteio login -t` and `siteio ui ?key=` keep working unchanged; all existing tests must still pass after every task.

## Review Focus

1. A hand-edited or truncated user file (invalid JSON) → that user is skipped, every other user still logs in; never a 500 for all `usr_` keys. Test: Task 1.
2. A person types `Alice` or ` alice ` at login → logs in as `alice`. Test: Task 5.
3. A 1 MB password at login or on change → refused cheaply, no argon2 work, still counted as a failure. Test: Task 1 (store) and Task 5 (route).

5. `/users/Alice`, `/users/a.b`, `/users/../x` → 404, never a 500 or a file outside `users/`. Test: Task 6.

```ts
import { existsSync, mkdirSync, readdirSync, readFileSync, rmSync, writeFileSync } from "fs"
import { join } from "path"
import { randomBytes } from "crypto"
import type { User, UserInfo, UserKey, UserKeyInfo } from "../../types.ts"
import { ValidationError } from "../../utils/errors.ts"
import { generateUserKey, hashGrantToken } from "../../utils/grant-token.ts"
import { NAME_RE } from "./tenants.ts"

export const SESSION_TTL_MS = 7 * 24 * 60 * 60_000
const MIN_PASSWORD = 8
const MAX_PASSWORD = 1024

// A password to print once: 24 base64url characters.
export function generatePassword(): string {
  return randomBytes(18).toString("base64url")
}

function normalize(username: unknown): string {
  return typeof username === "string" ? username.trim().toLowerCase() : ""
}

function hashPassword(password: string): Promise<string> {
  if (password.length < MIN_PASSWORD || password.length > MAX_PASSWORD) {
    throw new ValidationError(`Password must be ${MIN_PASSWORD} to ${MAX_PASSWORD} characters`)
  }
  return Bun.password.hash(password)
}

// Checked when the username is unknown, so a miss costs as much as a wrong password.
let placeholderHash: Promise<string> | null = null
const placeholder = () => (placeholderHash ??= Bun.password.hash(randomBytes(16).toString("hex")))

// People who can log in, one JSON file per user under <dataDir>/users/. A user
// holds its keys: one per CLI login ("machine") and one per admin UI session.
// Only the password hash and key hashes are stored. No cache: on-box commands
// (`siteio agent password`) write these files from another process, and a
// server has few users, so every lookup reads the folder.
export class UserStore {
  private dir: string

  constructor(dataDir: string, private now: () => number = Date.now) {
    this.dir = join(dataDir, "users")
    if (!existsSync(this.dir)) mkdirSync(this.dir, { recursive: true, mode: 0o700 })
  }

  // The file of a valid username, or null: a name from a request never becomes a path unchecked.
  private path(username: string): string | null {
    return username.length <= 63 && NAME_RE.test(username) ? join(this.dir, `${username}.json`) : null
  }

  private write(user: User): void {
    writeFileSync(this.path(user.username)!, JSON.stringify(user, null, 2), { mode: 0o600 })
  }

  private expired(key: UserKey, now = this.now()): boolean {
    return !!key.expiresAt && Date.parse(key.expiresAt) <= now
  }

  get(username: string): User | null {
    const file = this.path(normalize(username))
    if (!file || !existsSync(file)) return null
    try {
      return JSON.parse(readFileSync(file, "utf-8")) as User
    } catch {
      return null // a hand-edited or truncated file is no one
    }
  }

  list(): User[] {
    return readdirSync(this.dir)
      .filter((f) => f.endsWith(".json"))
      .map((f) => this.get(f.slice(0, -".json".length)))
      .filter((u): u is User => u !== null)
      .sort((a, b) => a.username.localeCompare(b.username))
  }

  hasAdmin(): boolean {
    return this.list().some((u) => u.role === "admin")
  }

  async create(input: { username: string; role: "owner" | "member"; tenant?: string; password: string }): Promise<User> {
    const username = normalize(input.username)
    if (!this.path(username)) throw new ValidationError("Username must contain only lowercase letters, numbers, and hyphens")
    if (username === "admin") throw new ValidationError("'admin' is reserved for the server's admin")
    if (input.role !== "owner" && input.role !== "member") throw new ValidationError("Role must be 'owner' or 'member'")
    if (input.role === "owner" && !input.tenant) throw new ValidationError("An owner belongs to a tenant: give its domain")
    if (this.get(username)) throw new ValidationError(`User '${username}' already exists`)
    const user: User = {
      username,
      role: input.role,
      ...(input.tenant && { tenant: input.tenant }),
      passwordHash: await hashPassword(input.password),
      createdAt: new Date(this.now()).toISOString(),
      keys: [],
    }
    this.write(user)
    return user
  }

  // Creates the admin on first use; otherwise resets its password and ends its sessions.
  async setAdminPassword(password: string): Promise<User> {
    const existing = this.get("admin")
    if (existing && existing.role !== "admin") throw new ValidationError("A user named 'admin' exists and is not the admin")
    const user: User = existing ?? { username: "admin", role: "admin", passwordHash: "", createdAt: new Date(this.now()).toISOString(), keys: [] }
    user.passwordHash = await hashPassword(password)
    user.keys = user.keys.filter((k) => k.kind === "machine")
    this.write(user)
    return user
  }

  // Sets the password and ends the user's sessions, except `keepSessionId` (the
  // caller's own). Machine keys keep working.
  async setPassword(username: string, password: string, keepSessionId?: string): Promise<void> {
    const user = this.get(username)
    if (!user) throw new ValidationError(`No user '${normalize(username)}'`)
    user.passwordHash = await hashPassword(password)
    user.keys = user.keys.filter((k) => k.kind === "machine" || k.id === keepSessionId)
    this.write(user)
  }

  // The user, when `password` is theirs. An unknown user costs the same work.
  async verifyPassword(username: unknown, password: unknown): Promise<User | null> {
    if (typeof password !== "string" || password.length === 0 || password.length > MAX_PASSWORD) return null
    const user = this.get(normalize(username))
    const ok = await Bun.password.verify(password, user?.passwordHash || (await placeholder()))
    return user && ok ? user : null
  }

  addKey(username: string, kind: UserKey["kind"], name: string): { key: UserKey; secret: string } {
    const user = this.get(username)
    if (!user) throw new ValidationError(`No user '${normalize(username)}'`)
    const now = this.now()
    const secret = generateUserKey()
    const key: UserKey = {
      id: `key_${randomBytes(4).toString("hex")}`,
      kind,
      name: name.slice(0, 100),
      hash: hashGrantToken(secret),
      createdAt: new Date(now).toISOString(),
      ...(kind === "session" && { expiresAt: new Date(now + SESSION_TTL_MS).toISOString() }),
    }
    user.keys = [...user.keys.filter((k) => !this.expired(k, now)), key]
    this.write(user)
    return { key, secret }
  }

  resolveKey(secret: string): { user: User; key: UserKey } | null {
    if (!secret.startsWith("usr_")) return null
    const hash = hashGrantToken(secret)
    for (const user of this.list()) {
      const key = user.keys.find((k) => k.hash === hash)
      if (key) return this.expired(key) ? null : { user, key }
    }
    return null
  }

  activeKeys(user: User): UserKey[] {
    return user.keys.filter((k) => !this.expired(k))
  }

  revokeKey(username: string, id: string): boolean {
    const user = this.get(username)
    if (!user || !user.keys.some((k) => k.id === id)) return false
    user.keys = user.keys.filter((k) => k.id !== id)
    this.write(user)
    return true
  }

  delete(username: string): boolean {
    const file = this.path(normalize(username))
    if (!file || !existsSync(file)) return false
    rmSync(file)
    return true
  }

  deleteTenantUsers(domain: string): string[] {
    const gone = this.list().filter((u) => u.tenant === domain).map((u) => u.username)
    for (const name of gone) this.delete(name)
    return gone
  }

  toInfo(user: User): UserInfo {
    return { username: user.username, role: user.role, tenant: user.tenant ?? null, createdAt: user.createdAt }
  }

  keyInfo(key: UserKey): UserKeyInfo {
    return { id: key.id, kind: key.kind, name: key.name, createdAt: key.createdAt, ...(key.expiresAt && { expiresAt: key.expiresAt }) }
  }
}
```

```ts
// Counts events per key (a client IP) in fixed windows. In memory only: a
// restart forgets it. Finished windows are dropped when the map grows large.
export class RateLimiter {
  private windows = new Map<string, { count: number; endsAt: number }>()

  constructor(
    private limit: number,
    private windowMs: number,
    private now: () => number = Date.now
  ) {}

  // Whether `key` has used up this window. Doesn't count.
  blocked(key: string): boolean {
    const w = this.windows.get(key)
    return !!w && w.endsAt > this.now() && w.count >= this.limit
  }

  hit(key: string): void {
    const now = this.now()
    const w = this.windows.get(key)
    if (w && w.endsAt > now) {
      w.count++
```

```ts
import { isCloudflareIp, parseIp } from "./analytics/client-ip.ts"

// 10/8, 172.16/12, 192.168/16, 127/8
const PRIVATE_V4: [bigint, number][] = [[0x0a000000n, 8], [0xac100000n, 12], [0xc0a80000n, 16], [0x7f000000n, 8]]

function isPrivate(ip: string): boolean {
  const p = parseIp(ip)
  if (!p) return false
  if (p.version === 4) return PRIVATE_V4.some(([base, bits]) => p.value >> BigInt(32 - bits) === base >> BigInt(32 - bits))
  return p.value === 1n || p.value >> 121n === 0x7en // ::1, fc00::/7
}

// The client's IP, for rate limits. Traefik reaches the agent from the Docker
// bridge, so a private or loopback peer is Traefik (or the box itself): the
// last X-Forwarded-For entry is then the address that connected to Traefik,
// which Traefik appends itself. Behind Cloudflare that address is an edge, and
// CF-Connecting-IP names the visitor. A public peer reached the agent
// directly, and its headers are not trusted.
export function requestIp(req: Request, peer: string): string {
  if (!isPrivate(peer)) return peer
  const forwarded = req.headers.get("x-forwarded-for")?.split(",").pop()?.trim()
  if (!forwarded || !parseIp(forwarded)) return peer
  const visitor = req.headers.get("cf-connecting-ip")?.trim()
  if (visitor && parseIp(visitor) && isCloudflareIp(forwarded)) return visitor
  return forwarded
}
```

```ts
import type { MeInfo, User } from "../../types.ts"
import { ValidationError } from "../../utils/errors.ts"
import { CLEAR_SESSION_COOKIE, sessionCookie, userFitsHost, type Auth } from "./auth.ts"
import { errorResponse, jsonResponse, readJson } from "./http.ts"
import { RateLimiter } from "./rate-limit.ts"
import type { Scope, TenantRegistry } from "./tenants.ts"
import type { UserStore } from "./user-store.ts"

// Password login for the admin UI, the caller's own account (/me) and, for the
// admin and tenant owners, managing users (/users). Works for every kind of
// key: the god key acts as the admin, a tenant key as its tenant's owner.
export class UserRoutes {
  // Failed password checks (login, or a wrong current password), per client IP.
  private failures = new RateLimiter(10, 60_000)

  constructor(
    private users: UserStore,
    private tenants: TenantRegistry
  ) {}

  // POST /auth/login, unauthenticated, on the API host of `scope`.
  async login(req: Request, scope: Scope, ip: string): Promise<Response> {
    if (this.failures.blocked(ip)) return errorResponse("Too many failed attempts, try again in a minute", 429)
    if (!this.users.hasAdmin()) return errorResponse("No users on this server yet", 409)
    const body = await readJson(req)
    const user = await this.users.verifyPassword(body?.username, body?.password)
    if (!user || !userFitsHost(user, scope)) {
      this.failures.hit(ip)
      return errorResponse("Invalid username or password", 401)
    }
    const { key, secret } = this.users.addKey(user.username, "session", "browser")
    return jsonResponse(this.meOf({ kind: "user", user, key }), 200, { "Set-Cookie": sessionCookie(secret) })
  }

  // Routes for an authenticated caller, or null when `path` isn't one of them.
  async handle(path: string, req: Request, auth: Auth, ip: string): Promise<Response | null> {
    if (path === "/auth/logout" && req.method === "POST") {
      if (auth.kind === "user" && auth.key.kind === "session") this.users.revokeKey(auth.user.username, auth.key.id)
      return jsonResponse({ loggedOut: true }, 200, { "Set-Cookie": CLEAR_SESSION_COOKIE })
    }
    if (path === "/me" && req.method === "GET") return jsonResponse(this.meOf(auth))
    if (path === "/me/password" && req.method === "POST") return this.changeOwnPassword(req, auth, ip)
    if (path === "/me/keys" && req.method === "GET") {
      return jsonResponse(auth.kind === "user" ? this.users.activeKeys(auth.user).map((k) => this.users.keyInfo(k)) : [])
    }
    if (path === "/me/keys/current" && req.method === "DELETE") {
      const revoked = auth.kind === "user" && this.users.revokeKey(auth.user.username, auth.key.id)
      return jsonResponse({ revoked })
    }
    const own = path.match(/^\/me\/keys\/(key_[0-9a-f]+)$/)
    if (own && req.method === "DELETE") {
      if (auth.kind !== "user" || !this.users.revokeKey(auth.user.username, own[1]!)) return errorResponse("Key not found", 404)
      return jsonResponse({ revoked: true })
    }
    return null
  }

  private meOf(auth: Auth): MeInfo {
    if (auth.kind === "user") {
      return { username: auth.user.username, role: auth.user.role, tenant: auth.user.tenant ?? null, currentKeyId: auth.key.id }
    }
    if (auth.kind === "tenant") return { username: null, role: "owner", tenant: auth.tenant.domain, currentKeyId: null }
    return { username: null, role: "admin", tenant: null, currentKeyId: null }
  }

  private async changeOwnPassword(req: Request, auth: Auth, ip: string): Promise<Response> {
    if (auth.kind !== "user") return errorResponse("Only a user account has a password", 400)
    if (this.failures.blocked(ip)) return errorResponse("Too many failed attempts, try again in a minute", 429)
    const body = await readJson(req)
    if (typeof body?.new !== "string") return errorResponse("'new' is required")
    if (!(await this.users.verifyPassword(auth.user.username, body.current))) {
      this.failures.hit(ip)
      return errorResponse("Current password is wrong", 403)
    }
    try {
      await this.users.setPassword(auth.user.username, body.new, auth.key.kind === "session" ? auth.key.id : undefined)
    } catch (err) {
      if (err instanceof ValidationError) return errorResponse(err.message, 400)
      throw err
    }
    return jsonResponse({ changed: true })
  }
}
```

```ts
  private reachOf(auth: Auth): Reach {
    if (auth.kind === "god") return { all: true }
    if (auth.kind === "tenant") return { tenant: auth.tenant.domain }
    if (auth.kind === "user" && auth.user.role === "admin") return { all: true }
    if (auth.kind === "user" && auth.user.role === "owner" && auth.user.tenant) return { tenant: auth.user.tenant }
    return null
  }

  private async manage(path: string, req: Request, reach: Reach): Promise<Response> {
    if (!reach) return errorResponse("Not found", 404)
    // An owner reaches its tenant's members; anyone else is "not found" to it.
    const reaches = (u: User) => "all" in reach || (u.tenant === reach.tenant && u.role === "member")

    if (path === "/users" && req.method === "GET") {
      return jsonResponse(this.users.list().filter(reaches).map((u) => this.users.toInfo(u)))
    }
    if (path === "/users" && req.method === "POST") return this.createUser(req, reach)

    const m = path.match(/^\/users\/([a-z0-9-]+)(\/password)?$/)
    const target = m ? this.users.get(m[1]!) : null
    if (!m || !target || !reaches(target)) return errorResponse("User not found", 404)

    if (!m[2] && req.method === "DELETE") {
      if (target.role === "admin") return errorResponse("The admin can't be deleted", 400)
      this.users.delete(target.username)
      return jsonResponse({ deleted: target.username })
    }
    if (m[2] && req.method === "POST") {
      if (target.role === "admin") {
        return errorResponse("Change the admin password from the admin account, or on the server with `siteio agent password`", 400)
      }
      const password = generatePassword()
      await this.users.setPassword(target.username, password)
      return jsonResponse({ username: target.username, password })
    }
    return errorResponse("Not found", 404)
  }

  private async createUser(req: Request, reach: NonNullable<Reach>): Promise<Response> {
    const body = await readJson(req)
    if (!body || typeof body.username !== "string") return errorResponse("'username' is required")
    const role = body.role ?? "member"
    if (role !== "owner" && role !== "member") return errorResponse("'role' must be 'owner' or 'member'")
    const asked = typeof body.tenant === "string" && body.tenant ? body.tenant.trim().toLowerCase() : undefined

    let tenant: string | undefined
    if ("all" in reach) {
      if (asked && !this.tenants.tenants.some((t) => t.domain === asked)) return errorResponse(`No tenant '${asked}'`)
      tenant = asked
    } else {
      if (role !== "member") return errorResponse("Only the admin can add an owner", 403)
      if (asked && asked !== reach.tenant) return errorResponse(`You can only add users to ${reach.tenant}`, 403)
      tenant = reach.tenant
    }

    const password = generatePassword()
    try {
      const user = await this.users.create({ username: body.username, role, tenant, password })
      return jsonResponse({ user: this.users.toInfo(user), password })
    } catch (err) {
      if (err instanceof ValidationError) return errorResponse(err.message, 400)
      throw err
    }
  }
```

```ts
// On-box: set or reset the admin's password (creates the admin on first run).

export async function agentPasswordCommand(options: { json?: boolean; password?: string }): Promise<void> {
  const dataDir = getAgentDataDir()
  const password = options.password ?? generatePassword()
  try {
    await new UserStore(dataDir).setAdminPassword(password)
  } catch (err) {
    console.error(formatError(err instanceof Error ? err.message : String(err)))
    process.exit(1)
  }

    return
  }
  const domain = loadAgentConfig(dataDir).domain
  console.error(formatSuccess("Admin password set"))
  console.error(`  Username: admin`)
  console.error(`  Password: ${chalk.bold(password)}`)
  if (domain) console.error(chalk.gray(`  Log in at https://api.${domain}/ui`))
  if (!options.password) console.error(chalk.yellow("  ! Shown only once."))
}
```
